# Syncron
CSE 108 JavaFX Project

Installation Guidelines:
1. Download the zip file(or clone) from the syncron network branch(not main) repository.
2. Download the zip file(or clone)from the kerenel-server main branch repository.
3. Extract both zip files in your desired location(if downloaded).
4. Now open both folders(Syncron-network and kernel-server) in intellij as projects in different windows separately.
5. Build maven script and download jdk-25 if pops up.
6. Now in kernel-server go to src/main/java/com/kernel/kernel_server/utils and run KernelServerApplication.java.
7. Now in Syncron-network go to src/main/java/com/syncron and run HelloApplication.java
